Issue 3: Course capacity requirement
--------------------------------------------------
HTTP Status:
Expected 400 when a Course is full.

Cause:
The project requires enrollment to be rejected when the
Classroom capacity is reached.

However, the provided entity relationship table does not define
a relationship between Course and Classroom.

Course belongs to Program and Instructor.
Classroom belongs to Department.

Fix / Decision:
No Course-Classroom relationship was added because Phase 1
requires relationships to match the provided entity table exactly.

Status:
Requirement/schema mismatch - requires instructor clarification.
